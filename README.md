# Extract wiki Data

The script requires Node version 22 or higher.

This is written in Typescript and thus you need to build the script. The Build files will be generated in "out/" directory.

**.env** file needs to be created if you are trying to run this script locally.

All of the variables are given in **.env.example** that needs to be defined.

## How to set up and run the script

`npm install`
`npm run build`

The above command will download all the dependencies and libraries to run the script.

The Build files will be generated by running the 2nd command. Saved in "out/" folder in your current working directory.

Check "tsconfig.json" for all the Typescript related configurations.

Check "package.json" for the project related info. You can also find the scripts to run inside this file.

### Running the Scripts

`npm run indexer:delete`

The above command runs a simple script that will delete the AI Search Index. The Logic is defined in the "src/delete.ts"

`npm run indexer:create`

This command will create the Azure AI Search index as defined in the environment variables. And it is upserted to AI Search via "src/setup.ts"

- The Data is extracted from ADO Wiki, as defined in "src/extract.ts".
- Embedding and chunking is done in "src/embedder.ts"
- The definition for the AI Index and all the definition for Embedding is in the "src/utils.ts"

Always ensure the AI Index is deleted before running the create command to create the index.
In practice, delete is run first and then create.
